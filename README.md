# 全球公民 · Global Citizen

一份关于护照、居留与移民路径的 3D 星图笔记（2026-10）。打开：https://curiousandy.github.io/

- 拖动旋转，滚轮或双指缩放，点一个球看结论和可信度。
- 手机：点「倾斜控制」后倾斜手机。电脑：点「手势控制」，用摄像头捏合拖动、双手缩放、张开手掌复位。
- 内容是个人探索整理，不构成法律或移民建议。
